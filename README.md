# 古估股 GitHub Pages

此資料夾目前包含：
- `index.html`：古估股支援首頁
- `delete-account.html`：Google Play 可使用的帳號刪除申請公開頁面

## 發布方式
1. 在 GitHub 建立公開 Repository，例如 `gugu-support`
2. 將這兩個 HTML 檔案上傳到 Repository 根目錄
3. Repository → Settings → Pages
4. Source 選 `Deploy from a branch`
5. Branch 選 `main`，Folder 選 `/(root)`，按 Save
6. 發布後帳號刪除網址通常會是：
   `https://你的GitHub帳號.github.io/gugu-support/delete-account.html`

目前隱私權政策仍為專案修訂稿，請勿把尚未完成的正式 HTTPS、備份規則或正式刪除網址描述成已完成。
